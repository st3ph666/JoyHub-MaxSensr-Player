# v1.4.13 — FR/EN + Funscript Loader Fix

This release improves compatibility and makes the JoyHub MaxSensr Funscript Player easier to share with both French- and English-speaking users.

## What's new

- Added live **French / English** interface switching
- Fixed untranslated interface status text
- Improved `.funscript` loading: supports standard JSON and concatenated JSON blocks
- Retains **live controls** during playback
- Retains **Ultra-slow OSC pulse mode** with Pulse ON, Pause OFF, and Pulse Force
- Retains the graph seek/reconnect fix
- Improved dark combobox readability and interaction

## Main functions

Direct BLE control of the JoyHub `J-MaxSensr`, synchronized MPV video playback, OSC, VIB and CON controls, vibration/constriction patterns, full-timeline funscript graph, and automatic funscript detection.
